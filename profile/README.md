## Mavergreen's goal:

By providing modern dev tools -- some familiar, some homegrown --
give developers leverage to ship modern software for Mavericks.

Clang and Swift, of course, but also Drydock and Recaulk.

## Mavergreen's must-haves:

### 1. Runs on 10.9

Also on modern macOS and Linux, if that helps target Mavericks.

### 2. Builds on 10.9

Also from modern macOS and Linux.

### 3. Releases on GitHub

Auto-updated by Renovate.

### 4. Updates on your system

Sparkle updaters.
