## The Mavergreen rules:

- Everything runs on Mac OS X 10.9 Mavericks
    - and anything that helps target Mavericks also runs on modern macOS and Linux
- Everything is buildable directly on 10.9
    - and on modern macOS and Linux
- Everything is built and released on GitHub
    - after passing on-target tests in a Mavericks VM
- Everything is auto-updated by Renovate
- Everything has a Sparkle updater
